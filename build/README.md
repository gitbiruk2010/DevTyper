# Icon Placeholder

For building the application, you'll need to add application icons:

- **macOS**: `icon.icns`
- **Windows**: `icon.ico`
- **Linux**: `icon.png` (512x512)

You can generate these from a PNG file using tools like:
- https://www.electronjs.org/docs/latest/tutorial/application-distribution
- Online icon converters
- electron-icon-builder package

For now, the app will build with default icons.
